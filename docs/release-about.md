# MouseDock 本版说明 & 关于

> 版本快照：2026-10-31 夜间构建
> 产物：`app\MouseDock.exe`（单文件，自包含，约 81 MB）

## 一、本版更新（对比上一版）

### 1. 设置页重做

原来那一整块「数据源」拆掉了。

`自动检测 / 演示 / JSON / HID 实验` 四个按钮、`安全模式` 勾选框、状态提示、
`打开数据目录`、`查看探测报告`、`抓取 2.4G 报文` —— 全部删除。

理由是这些开关面向开发调试，普通用户一辈子不会点第二次，反而占掉半屏。

留下来的那一块改名 **「刷新与提醒」**：

| 项目 | 范围 |
|---|---|
| 刷新间隔 | 1 – 120 秒（原最小 5 秒） |
| 低电量提醒 | 10% / 20% / 30% / 40%，默认 20% |

顺带修掉一个隐蔽问题：旧 `settings.json` 里如果残留 `"Provider": "json"`，
界面删了按钮但值还在生效，面板会停在「外部 JSON · 0 台在线」读不到真设备。
现在启动时强制覆盖为 `auto`，磁盘上的脏值也一并改写。

### 2. 显示方式统一为三选一

`主面板 / 迷你 / 悬浮图标` —— 同一时间只露一个。

原来设置页一套逻辑、右键菜单另一套逻辑，右键里还挂着三个独立的
`隐藏/显示` 开关，能同时点开三个窗口。现在两边共用同一个 `SurfaceMode`：
右键菜单改成 `● 主面板 / ○ 迷你窗 / ○ 悬浮图标` 单选，点了立刻生效。

旧配置里三个开关全开的，启动时按「迷你 > 图标 > 主面板」收敛成一个。

### 3. 三个窗口各用各的背景

`卡片窗` / `迷你窗` / `悬浮图标` 各存一个图片路径，互不干扰。

底部「窗口背景」卡片三行，每行一组 `选择图片 / 清除`。
不设就用预设主题渐变。

背景图按 2048 宽解码（`DecodePixelWidth`）并配 `BitmapScalingMode.HighQuality`，
缩放时边缘不发虚。原图本身低于 2K 的，放大只会变糊，不会凭空长出细节 ——
真正的超分要挂 ONNX Runtime + ESRGAN 一类模型，几十兆外加授权问题，
不塞进这个单文件程序里。

### 4. 窗口行为

设置页新开一组，两个开关：

- **窗口置顶** —— `Topmost`，压在其他窗口上面
- **鼠标穿透** —— `WS_EX_TRANSPARENT | WS_EX_LAYERED`，点击直接穿到下面的程序。
  开了之后点不到窗口，得从托盘图标右键菜单关掉

### 5. 悬浮图标

- **显示全部已连接设备**：不再只显示主设备，最多五行，一行一台
- **按设备名自动撑宽**：中文约 9.2px/字、拉丁约 5.3px/字，加内边距，
  96 起、220 封顶；设备多一台就高一行
- **可拖动**：原来 `DragMove()` 抛的异常被 `catch { }` 吞掉，按下去没反应；
  改手动拖（记录起点 → 改 `Left/Top` → 落盘位置）
- **滚轮缩放、拖动取景** 保留

### 6. 托盘图标

从固定图标改成 **圆角方块 + 电量数字**，四态配色：

```
正常    #7FE7C4  绿
低电量  #FF6B6B  红    低于设置阈值时每 600ms 在红/暗红之间闪
充电    #7FE7C4  绿    提示文字标「充电中」
未知    #8A8A8A  灰    显示 —
```

`Battery.Refreshed` 一触发就重画。插上充电器闪烁立即停止。

### 7. 主题

保留原四套：`深色薄荷`、`云雾浅色`、`暮色蓝紫`、`冰雾磨砂`。

浅色主题下的文字/卡片画刷单独定义过，不会出现白字白底。

### 8. 修复

- 右键菜单里「主题 ·」四行显示成乱码（`涓婚 ·`），是某次批量改文件时
  GBK 误码留下的，全文扫描后清零
- 设置页「自定义背景 · 取主色」整块删除 —— 用户要的是换图，不是从图里抽色改主题

### 本版没做的事

- **图标样式 / 图标外形 / 板块样式** 三个区块做完又撤了（需求变更）。
  代码本体（七种样式的图层、四种外形逻辑）保留在 `IconWindow` 里，
  只是设置页没有入口了，需要时加回 UI 即可
- **内置图库** 做过一版（16 张 Picsum CC0 照片 + gallery 目录），
  按需求删除，目录也已清理
- **AI 补帧 / 超分** 未实现，理由见上

### 除上述协议外的通用能力

- **标准 HID 电池用法**（`UsagePage 0x06 / Usage 0x20`）：任何按规范上报的鼠标键盘
- **蓝牙 GATT** `0x180F / 0x2A19`：BLE 外设通用
- **经典蓝牙耳机** HFP AT 指令 → 厂商 RFCOMM 兜底

### 验证状态（别当成全都实测过）

| 状态 | 设备 |
|---|---|
| **实机验证** | 罗技 G304（90%）、狼蛛 AULA SC580（44–51%）、VGN Neon75 Air 键盘（100%）、迈从 A7（40%） |
| **仅编译验证** | 其余 31 条 —— 帧格式、字节偏移都来自反汇编，没有实物对拍 |

其中有几个我自己就知道有缺口：

- `akko` 家族的响应长度和电量字节**未确认**
- `ipi_pix` 只实现到校验层，电量字段**未确认**
- Sora V3 的三条命令映射表没在反汇编里展开
- RAWM 的 JSON 分片重组没有实物试过
- SCYROX 的 `rid` 是 1–16 暴力试出来的

读不到电量时面板显示 `—`，绝不编数字；有历史值的会降透明度标注旧值。

## 三、已知限制

1. **2.4G 接收器通用号**：`089D:062F` 是 llTECH OEM 接收器通用号，多个品牌共用，
   单靠 VID:PID 认不出具体型号，要靠设备 Identify 应答里的 4 字节 ASCII 型号串
2. **设备睡眠期间读不到**：多数 2.4G 设备休眠后不响应，需要动一下鼠标/键盘唤醒
3. **单实例**：`--detect` 无法在 GUI 运行时执行（互斥锁），先退托盘再跑
4. **数据目录**：`%APPDATA%\MouseDock\`，含 `settings.json`、`battery-cache.json`、
   `vendor-identity.json`
