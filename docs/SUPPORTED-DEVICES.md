# 支持设备

> v1.1.1 当前启用范围以 [识别策略](RECOGNITION-1.1.1.md) 和 [六款已验证参考设备移植矩阵](REFERENCE-1.0.2-PORT.md) 为准。下文历史适配列表包含尚未重新启用的协议，不能作为当前运行时支持承诺。

判定说明：

- **识别**：设备能出现在面板上并且名称正确
- **电量**：能读出真实百分比（`—` 表示当前未取得有效读数，不等同于硬件不支持）

下表混合历史实测、静态协议与待核验条目，逐行备注才是证据范围，不能统称实测支持。VID/PID 与协议的全量清单（含还没支持的）在 [device-db](device-db/README.md)，四份文件：给人看的 md、给程序吃的 json/csv、以及能直接并库的 `devices-merged.json`。

### 蓝牙耳机边界

当前耳机按用户要求仅提供系统音频名称与控制，不启用HID/GATT/私有协议电量。旧报告中的系统电量属性或协议尝试不作为当前耳机电量支持承诺。

## 有线

`4C4A:4155` 为共享USB音频编号，不再按该编号命名为竹林鸟玄武。名称来自实际Windows音频端点，电量功能关闭。

| 情况 | 识别 | 电量 |
|---|---|---|
| USB 有线键鼠 | ✅ 通道显示「有线」 | — 标准 HID 无电量上报 |

有线设备若厂商在私有 HID 集合里提供电量，可以按厂商协议接入（同 AULA 的方式）。
