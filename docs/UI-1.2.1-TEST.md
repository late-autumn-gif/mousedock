2026-11-14：原设置模板中的固定半透明白色轨道、复选框边框、滚动条在浅粉等主题中融入背景。现在根据实际主题卡片合成背景生成不透明的边界和轨道，检查其相对背景的内部对比度目标为 3.2；强调色仅在控件局部按需调整，勾选使用与填充对比充分的矢量笔画。用户的主题颜色配置不改写，交互仍使用淡底色，导航不恢复系统蓝色高亮。

透明悬浮样式原先沿用浅色主题的深色文字；「轻量数字」即使未开启隐藏底色也没有底板。现在通过透明绘制门禁识别这些情况，给数字加细深色轮廓、为过暗文字选择清晰的前景；图标和低电量色在必要时提亮并保留色相。缓存上限 32 种颜色，不引入额外轮询或后台任务。没有对未采样壁纸声称自动识别背景；黑白两种极端背景已经生成合成截图验证。

过期数字在透明样式中保持可读，并加「旧」标记及悬停状态说明；仍是原来的上次读数，不转成新数据、不恢复充电动画。未知仍为 —。任务栏 Compact 绘制分支不使用透明悬浮修正。
