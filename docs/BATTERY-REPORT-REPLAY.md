# 电量错误报告离线重放

## 采集

1. 用接收器连接设备，唤醒外设，并保持 2.4G 模式。
2. 在 MouseDock 里选择「导出错误报告」。有接收器条目就选对应条目，列表中没有时选全部设备。
3. 保存后把 ZIP 内的 `battery-replay.json` 发给维护者，并附上商品完整型号。有原厂软件的读数或固件版本时可以一并附上。

程序会在后台重新扫描 HID，遵守安全模式和设备识别设置。重放文件记录扫描时间、构建编号、接收器与集合的关联、接口能力和电量查询结果。关联编号只在这份报告内有效。文件保留原始 HID 产品名及与已知电量协议匹配的报文，发送前可预览。与电量协议无关的输入只记录长度和拒绝状态。完整 ZIP 中的旧版诊断文件仍可能包含设备路径和本机设置。

## 重放

在 PowerShell 中运行：

```powershell
Start-Process -FilePath '.\MouseDock.exe' -Wait -ArgumentList '--replay-report ".\报告.zip" ".\重放结果.json"'
```

也可将 ZIP 路径换成单独的 `battery-replay.json`。重放只读文件，不打开 HID 接口，也不会启动常驻窗口。

- `Results` 是重新核对接口并用现有解析器重放的结果。当前覆盖狼蛛 SC580、SC630 Pro 和英菲克 IN9、IN9 Pro。
- `Observations` 是采集时扫描得到的结果，包含其他 HID 路径和缓存标记。这些结果没有经过报文重放。
- `captured` 表示报文通过校验，百分比对应采集时刻。只有型号证据时，电量为 `null`。超时、未找到集合、缺少响应或无已验证的换算依据时，电量保持未知。
