# v1.1.1 识别规则重整

这是本项目的版本重编号，以 a0cd744 为基线，不是另一作者 1.0.2 的升级版本。本次将其明确 verified 的六款设备的识别、电量事务、充电字段和可选身份查询改写为 C#，仍保留有限 profile、身份检查和精确接口匹配。第三方验证和本项目离线测试不冒充本项目实机复验。许可与归属见根目录 THIRD-PARTY-NOTICES.md。

## 当前启用的主动 HID 读取

基于仓库既有实机记录，RecognitionPolicy 保留四组接收器：089D:062F（SC580 所用公版接收器，型号仍须 Identify 确认）、391D:2A05（Neon75 Air）、3837:100B（MCHOSE A7 V2 Ultra+）、5253:1021（MCHOSE A7）。这些是历史实机证据，本次没有重新插拔验证全部设备。另外启用下方六款的专用有限协议路径，必须匹配私有用法页/用法和报告长度才读取。

另有用户明确要求的 [EWEADN X23SE 精确适配](EWEADN-X23SE.md)：依据旧报告的原始产品名、VID/PID、MI_02、用法和 65/65/0 长度启用有限 FREQ 电量事务，实际报告编号仍须运行时确认。这是待实机验证的适配，不计入第三方 verified 六款，也不宣称已经读到真实电量。

上述路径以外的 HID 设备仍可作为候选显示，保留描述符名称，但不执行主动厂商查询。已有其他协议实现和离线解析测试保留，不因解析测试通过就自动启用。SC630 Pro、ROG、Logitech 及下方六款以外的 ATK 等仍受限制。鼠标、键盘的蓝牙发现与标准电池服务保持原路径；耳机改为独立音频控制页，仅名称、音量与麦克风静音，见 HEADSET-AUDIO.md。

## 行为变化

- 原始名称 RawName 与 ConfirmedModel 分别保存；接口、接收器、外设确认及有效电量分别记录，并进入反馈报告。
- 4C4A:4155 不再命名为竹林鸟；没有身份应答就不确认型号。此 ID 的 Consumer Control 仅作为候选音频设备。
- HID 实例基于 USB 物理父节点（缺少时退回完整路径）生成哈希 ID。先注册全部接口再查询，只访问同一实例的通道。
- 不再因 SC580 等型号别名跨连接自动合并；无法证明同一实例时保留独立条目，避免误合并两台设备。更换 USB 端口可能产生新 ID，需要重新选择显示设备。
- 身份和电量使用新的实例缓存文件，旧 VID/PID 缓存不迁移。重识别会清除此实例缓存。缓存读数保留 stale 标记，不标为新鲜电量。
- 停用通用 Feature 数值形状、ByShape 和 LegacyShape 兜底。MCHOSE K5 Ultra 不再撞上 K 数字键盘正则。
- 版本设为 1.1.1；更新通道限制在 1.1.x，避免重编号后升级回历史 1.4.x。未来跨系列升级需显式调整通道。

## 验证范围

新增共享耳机 ID、K5 复合描述符回归依据为用户提供的 1.3.9 报告；同型号双实例、嵌套通道隔离使用合成用例，未冒充真实 USB 捕获。无用户路径、设置、完整报告或第三方程序随源码发布。

已移植 1.0.2 明确标记 verified=true 的六款的电量支持；没有把它的全部 252 条清单视作已验证。仍不能宣称已解决其他电脑 SC580 / SC630 Pro 的硬件读取失败。完整矩阵、验证方法和边界见 [六款移植说明](REFERENCE-1.0.2-PORT.md)。

1.0.2 数据库四组清单共 252 条（devices=26、wireless_keyboards=1、wireless_receivers=221、wireless_usb=4），仅 devices 内 6 条明确 verified=true；其余无线清单无 verified=true 项。该标记是第三方声明，本次未独立实机复验。

这六条的 VID/PID + 私有用法页/用法已作为有限描述符识别规则加入：EWEADN Z7 3554:F517 FF02/2；Scyrox V12M 395A:0006 FF00/2；ATK Zero 373B:11D8 FF02/2；ATK F1 V3 Ultimate+ 373B:1278 FF02/2；Rapoo VT9S V2 24AE:1453 FF00/2；Ninjutso Sora V2 1915:AE8A FFA0/1。辅助键盘集合或相邻 PID 不会确认型号。

这六款已接入扫描流程中的专用电量读取器，并与原程序纯函数生成的 2184 组报文结果对照。没有移植 DPI 设置、配对、固件升级或写配置功能，也没有打包第三方程序。读取失败时保留具体拒绝原因；缓存读数仍明确标为旧值。
