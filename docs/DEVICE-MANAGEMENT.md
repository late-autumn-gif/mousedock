# 设备显示与手动识别（1.3.5）

设置中的勾选状态统一控制主面板、迷你窗口、悬浮设备列表和电量托盘。显示列表最多取已勾选的前5台；全部取消勾选时显示空列表，不再自动回退到全部设备。设置仍列出所有当前发现的连接设备，方便恢复。

对设备行右键，可使用：

- **取消识别**：停止 MouseDock 后续的主动电量查询，清除旧读数并移出显示列表；管理条目保留。已经开始的查询允许结束，其旧结果不会恢复该设备。不会在 Windows 中禁用硬件或卸载驱动。
- **隐藏设备**：从所有显示列表中移除，继续进行正常电量刷新。设置中会标记已隐藏，重新勾选即可恢复。
- **重新识别**：重新启用识别、取消隐藏、勾选显示，并重新查询。1.3.6起保留上次有效电量与已确认型号；等待期间电量标记待刷新、停止充电动画，不再删除接收器电量历史缓存。进行中的旧样本不会覆盖此次重新识别。

右键菜单位于主卡片设备行、迷你设备格、悬浮设备标签和设置的设备条目。隐藏或取消识别后，到设置中的“显示设备”列表重新勾选，或者右键选择“重新识别”。仅使用现有已适配的协议；不向未知设备猜测发送厂商命令。竹林鸟玄武目前已确认身份，电量协议仍未适配，重新识别后可能继续显示未知。

设置新增 `DeviceSelectionInitialized`、`HiddenDeviceIds` 和 `DisabledRecognitionDeviceIds`。首次安装保留自动显示；一旦用户作出选择，即使明确选择空列表也会持久化。旧版已有非空 `SelectedDeviceIds` 自动迁移，防止后台首次异步发现设备时丢失原选择。断开设备的选择仍保存，重新连接后按原选择处理。设备分组仍沿用项目已有的 PhysicalKey/VID-PID 规则，同编号多个接收器尚未新增独立实例分组。

回归程序 `--verify-device-management <预览目录>` 使用实际 WPF 设置勾选控件、三种显示模板和菜单处理器，验证持久化、全部取消、隐藏/恢复、取消识别、重新识别及进行中的旧样本处理。测试数据明确标为测试设备，不代表本机真实读数。该检查不访问外设，也不覆盖用户设置。
