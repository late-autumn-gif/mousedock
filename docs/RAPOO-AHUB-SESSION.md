## 沿用项目原有方式

HidDiscovery 枚举 → InstanceScope 隔离物理实例 → 原 DeviceRoutes/ExtraDeviceRoutes 选择雷柏读取器 → ReferenceQueryGate 执行有界事务 → 原 BatteryService 刷新和显示。设备发现、类型判定、去重、设备选择与 UI 模型不另建一套。仍只接受已采样的无线 24AE:1417、revision0105 和三组精确通道。

RapooAhubReader 每次刷新打开并重新核验报告07电量通道、报告06输出通道、Feature08应答通道。先清旧输入队列，再执行15次白名单内的配置/当前DPI/固件只读查询，最后有界等待新报告07；不在初始化后再次清队列。正常完成或失败时，由原查询门禁工作线程释放接口。没有独立常驻会话、跨轮电量缓存或额外发现/退出钩子；保持原安全模式、识别开关和查询互斥门禁。

内部事务预算12秒，通知等待最多1.5秒，外部查询等待12.5秒。同步原生调用不能强制取消，原 ReferenceQueryGate 保留卡住工作线程的资源、同实例防重入及全局最多四个未结束工作线程；晚到响应经过时间校验，不作为新读数。该上限是故障保护，不是正常刷新耗时的实测结果。
