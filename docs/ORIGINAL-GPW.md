# 一代 GPW 适配（v1.1.1）

本包保留此前六款参考移植、X23SE、狼蛛 SC580/SC630 Pro 和耳机功能，版本保持1.1.1。本次依据用户旧报告和已核对的HID++字段接入专用读取，尚无GPW实机读数，不能将离线通过写成实机修复成功。

## 旧报告说明什么

用户提供的 MouseDock-report-20261105-162610.zip 中，C539原始产品名为USB Receiver，包含鼠标、辅助键盘、消费者控制及多个私有集合。与本次相关的三个集合为：

| 用法页/用法 | Input/Output/Feature | 本次行为 |
| --- | --- | --- |
| FF00/0001 | 7/7/0 | 不进入此专用路径 |
| FF00/0002 | 20/20/0 | 唯一电量通道候选 |
| FF00/0004 | 32/32/0 | 不作为HID++电量通道 |

旧报告诊断停在接口归并后，没有本轮完整HID++身份/电压事务。旧代码存在同步I/O和多个接口探测的阻塞风险；新版专用路径只读一个精确集合，并以工作线程总预算保护扫描。报告中的G HUB软件虚拟设备、gvinput虚拟触摸设备继续过滤。源码只保留去除真实PnP路径/序列号的合成回归，不提交用户报告。

## 名称与型号边界

- **046D:C539** 是接收器候选，不直接命名为GPW。先在本实例槽位1读取0x0005完整实时名称；仅一代GPW名称通过，SUPERLIGHT、G502等其他设备不套此模型。
- 名称服务没有提供完整名称时，可改读0x0003 GetDeviceInfo。按payload[6]传输位和payload[7..12]的紧凑型号表解析，只接受无线型号4079、USB型号C088；两者同时存在必须都正确，连续两次身份一致。不会在任意偏移搜索匹配字节。名称明确为其他型号时不走这条回退。
- **046D:C088** 是一代GPW直接USB型号，可独立确认描述符型号；仍需精确长报文集合才发电量查询。尝试设备端点1，名称服务和电压特征均不可用时可尝试FF。C539不以FF接收器端点代替外设。
- C539要求FF00/0002、20/20/0；C088要求FF00/0001或0002、20/20/0。未获得这类接口的固件版本不猜测其他长度或Feature布局。
- 同一USB物理父实例归并辅助集合；原始名称RawName保留USB Receiver，ConfirmedModel独立记录。没有型号证据时显示接收器占位，接收器发现、外设在线和电量成功各自记录。

## 电量和充电

仅查询0x1001电压，不发送配对、DPI、灯效、板载配置或固件命令。每次请求前排空已有队列，使用非零且变化的软件ID。只接收严格匹配20字节report11、同槽位、同特征、同函数、同软件ID的响应；拒绝回显、旧帧、短帧和松散ID回退。缺少两次有效电压响应时电量未知，已经取得的当前身份仍可保留。

0x1001的前两字节是大端mV，不能把0x10当16%。确认一代GPW后，调用已有LogitechGpwBattery模型估算：例如合成4096mV输入得到约93%，不是本次实机读数。该模型来自此前核对的G HUB pro_wireless_mouse_depot battery.xml的502个放电节点及充电锚点；插值/能量归一化由本项目实现，不保证与G HUB私有滤波或显示值完全相同。

标志位区分放电、充电、明确满电及不充电；未知充电状态、非法电压拒绝。4.2V充电平台对应多个电量值，电压不能唯一确定百分比时保持未知。只有合法电压配合明确满电状态才报100%，并且不显示活动充电动画。Note与报告将模型结果标明“估算（非设备直接百分比）”，不能作为精确电池SoC。

## 超时与实例

每个物理实例须只有一个精确长报文路径；同一路径重复枚举去重，多个不同候选路径不猜。打开后复核VID/PID和集合，禁止借另一个同型号接收器的接口、名称或电量。

整个协议事务有4秒预算，原生工作线程外部等待上限5秒；单次输出250ms、匹配响应窗口最多300ms。未能清空队列或未完整发送时停止该事务。Windows取消I/O后，原生缓冲、事件及句柄由原工作线程持有到真正完成；迟到结果不被下轮采用，沿用已有最多4个挂起查询限制。

安全模式、停用识别、缺少实例或集合时不发送查询。C539/C088不再进入旧通用LogitechHidpp.Probe、Feature临时线程或旧hint读取，也不会在报告导出时重新对相同VID/PID的全部设备发送探针。

## 实机使用

1. 退出旧版本，解压运行本包，连接接收器并唤醒鼠标。保持该实例识别开启、安全模式关闭后刷新。
2. 观察是否从接收器占位变为Logitech G Pro Wireless，以及电量说明是否为估算。充电平台显示未知符合本次边界。
3. 如果仍失败，导出新报告，查看hid-devices.txt的“GPW边界”或“GPW专用”。日志会包含集合缺失、软件ID/槽位不匹配、HID++错误、名称/型号身份、TX/RX、最后拒绝帧或电压换算失败阶段。
4. 提供新报告后才能按该固件真实响应调整规则。本包没有把其他Logitech设备或其他接收器全部放开。
