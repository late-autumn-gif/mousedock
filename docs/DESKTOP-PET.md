# MouseDock 桌宠

在「设置 → 显示方式 → 桌宠」开启，或从托盘菜单切换到桌宠。右键「桌宠角色」可选择蜡笔小新、心月狐、小鸟游六花和刻晴。

## 自由形态（默认）

角色会站立、眨眼，停留片刻后在原地坐下，起身后交替迈步，距离足够时偶尔小跑。单击会打招呼，双击会向上跳，在头部来回划动会触发摸头表情，拖拽会显示被拎起的姿势，松手后落地。横向拖拽和自主活动共用活动范围。右键可更换角色和大小，也可以调整活动范围或锁定位置。

放开鼠标后，自由形态会自动轮换走跑、跳跃、张望、挥手、鞠躬、坐睡和表情。动作顺序会洗牌。默认第一次等待约 5–8 秒，普通动作之间停留约 9–15 秒，跑步或跳舞等动作结束后会休息更久。站坐和表情带过渡，跳跃包含预备和落地缓冲。角色被悬停或抓取、打开菜单、开启减动效或切换桌前形态时暂停自主轮换。

右键「互动动作」可以直接播放 18 个动作，包含跑步、跳跃、挥手、转身、转圈、跳舞、坐下和睡觉。「互动动作 → 表情」可选择 19 项表情，部分表情共用图帧。快速松手会在活动区内短距离甩动，普通松手直接落地。动作入口在自由形态中可用。

「活动范围」可设为关闭、小范围（默认）或大范围。左右移动限制在电量框左侧的紧凑区域，区域随桌宠大小缩放，右边缘与电量框左边缘保持 5 个屏幕像素。自由形态的角色在电量框左侧活动。拖放只移动角色，活动范围以电量框旁的固定位置为基准。电量框在角色走动或拖放时保持原位。按住电量框上沿可以单独调整面板位置。悬停、拖拽、菜单、锁定位置或减少动态效果时会暂停走动。

## 桌前形态

右键勾选「键鼠动作联动」，角色会切换为坐在键盘和鼠标前的形态。小新桌前形态使用自由形态图集里的二次元头像，动作仍由现有独立键鼠部件驱动。移动鼠标会带动角色的鼠标手，按键会点亮对应的键位。取消勾选会回到自由形态，并取消后台键鼠注册。旧版设置里的默认联动标记不作为新版桌前形态的开启记录。

右键「显示设备」可勾选电量面板中的设备。「桌宠大小」提供 50%、75%、100%、125%、150% 五档。菜单还提供满电提醒、设置与隐藏桌宠。

右键开启「减少动态效果」会立即结束当前表情和动作，并暂停自动动作、键鼠联动和电量条动效。它也遵循 Windows 的界面动画设置。


## 在 Coopanion 中使用 MouseDock 角色

1. 从 [Coopanion 官方下载页](https://coo.palailab.org/guide/install/) 获取安装版或便携版。
2. 在 MouseDock 的桌宠菜单展开「Coopanion」，选择「启动 Coopanion」。首次找不到程序时，选择解压目录里的 `Coopanion.exe`。
3. 选择「导出四个角色的形象包」，在 Coopanion 设置的「装扮 → 导入」选择 ZIP，再选择一个角色。角色的走路、坐下、触碰和拖拽由 Coopanion 的形象接口驱动。
4. 入口启动 Coopanion 后，MouseDock 只显示电量。要恢复 MouseDock 自带桌宠，在电量框右键取消「在 MouseDock 只显示电量」。

形象包使用官方 Manifest 2 / API 2。两边各自保存位置和设置，后台键鼠同步属于 MouseDock 的桌前形态。


## 形象包与动作来源

对照 Coopanion 本地实际导入的四个 MouseDock 形象，图集和入口脚本与 MouseDock 源文件逐字节一致。Coopanion 导入形象时保存这些文件，角色行为则由其公共身体组件负责。MouseDock 的原生跑步、跳跃、拎起、落地和触碰在既有 WPF 行为系统中实现。参考 [Coopanion v0.2.23 身体组件](https://github.com/Pal-AI-Lab/Coopanion/blob/v0.2.23/packages/cortico-world-desktop-pet/web/kit/body.js)。
