# MouseDock 桌宠

在「设置 → 显示方式 → 桌宠」开启，或从托盘菜单切换到桌宠。右键「桌宠角色」可选择蜡笔小新、心月狐、小鸟游六花和刻晴。

开启「键鼠动作联动」后，移动鼠标会带动角色的鼠标手，左右键的按压状态显示在桌宠鼠标上。打字时，对应键位点亮为黄色，空格键排在靠近角色的一侧，指尖落在点亮的物理键位上。

右键「显示设备」可勾选电量面板中的设备。「桌宠大小」提供 50%、75%、100%、125%、150% 五档。菜单还提供锁定位置、减少动态效果、满电提醒、设置与隐藏桌宠。

单击桌宠角色会微笑并轻跳。双击会露出晕眩表情并左右摇晃，约 1.6 秒后恢复。空闲时会眨眼，偶尔探身、轻跳或晕眩，长时间闲置则闭眼休息。电量框与框沿头像在动作期间保持原位。

右键开启「减少动态效果」会立即结束当前表情和动作，并暂停自动动作、键鼠联动和电量条动效。它也遵循 Windows 的界面动画设置。
