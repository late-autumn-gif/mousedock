# MouseDock 桌宠

在「设置 → 显示方式 → 桌宠」开启，或从托盘菜单选择「切换到桌宠」。桌宠、主面板、迷你窗口、悬浮图标、任务栏和屏幕右侧共用同一显示方式选择。旧版开启了独立桌宠开关的设置会迁移到桌宠模式。

蜡笔小新、小鸟游六花和心月狐使用左侧全身角色和右侧带探头头像的原版电量框。每张卡片最多显示六台已勾选设备。每台设备各占一行，显示图标、名称、电量条和百分比，过期读数变暗。电量条左对齐，默认缩放下最长 148 个逻辑像素。点击设备行可切换角色跟随的设备，右键「显示设备」可更改与设置页同步的勾选状态。

悬停角色时，角色会朝光标方向倾斜。单击角色会播放一次对应的互动动作。拖动角色时会切换为腾空姿势，松手后保存位置并恢复当前电量状态对应的姿势。启用减少动态效果后仍可拖动和缩放。

滚轮上下可按 5% 缩放角色与电量框，默认 100%，范围 50%–150%。右键「桌宠大小」提供快捷档位。右键「桌宠角色」可切换角色。明确满电时使用原有的充电会话提醒。

原有全身图集用于各电量状态。根据三张交互参考图生成的透明图集按小新、心月狐、六花分行，每行依次为悬停、单击和拖动。电量数据与进度条由应用绘制。

确认充电时，横向电量线上沿会从左到右流动，长度跟随有效电量。休眠或读数过期后停止波浪。
