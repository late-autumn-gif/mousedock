# MouseDock 桌宠

在「设置 → 显示方式 → 桌宠」开启，或从托盘菜单选择「切换到桌宠」。桌宠、主面板、迷你窗口、悬浮图标、任务栏和屏幕右侧共用同一显示方式选择。旧版开启了独立桌宠开关的设置会迁移到桌宠模式。

蜡笔小新、小鸟游六花和心月狐使用左侧全身角色和右侧带探头头像的原版电量框。每张卡片最多显示六台已勾选设备。每台设备各占一行，显示图标、名称、电量条和百分比，过期读数变暗。电量条左对齐，默认缩放下最长 148 个逻辑像素。点击设备行可切换角色跟随的设备，右键「显示设备」可更改与设置页同步的勾选状态。

悬停角色时，角色会朝光标方向倾斜。单击角色会播放一次对应的互动动作。拖动角色时会切换为腾空姿势，松手后保存位置并恢复当前电量状态对应的姿势。启用减少动态效果后仍可拖动和缩放。

滚轮上下可按 5% 缩放角色与电量框，默认 100%，范围 50%–150%。右键「桌宠大小」提供快捷档位。右键「桌宠角色」可切换角色。明确满电时使用原有的充电会话提醒。

右键「桌宠角色 → 刻晴」可切换到刻晴。选中后，右键「刻晴动作」可播放元素战技「星斗归位」、元素爆发「天街巡游」或挥手。动作结束后恢复当前电量状态对应的姿势。启用减少动态效果后，动作菜单会停用。

原有全身图集用于各电量状态。根据三张交互参考图生成的透明图集按小新、心月狐、六花分行，每行依次为悬停、单击和拖动。电量数据与进度条由应用绘制。

确认充电时，横向电量线上沿会从左到右流动，长度跟随有效电量。休眠或读数过期后停止波浪。

充电中的实时电量协议复核仍未完成。


小新的九帧采用新表情，待机微笑、悬停侧看、点击笑开、拖动惊讶。小新现有独立闭眼帧，支持随机眨眼。

## 键盘桌宠（桌前形象）

v1.3.0 起，蜡笔小新、心月狐、小鸟游六花、刻晴四款角色统一改为坐在桌前敲键盘的形象。角色继续复用现有 PNG 九姿势图集和每个角色的配色，不再单独需要新美术资源；桌面、显示器、37 键键盘、鼠标和双手由 `DesktopPetDeskScene` 以 WPF 矢量绘制，内部按 300×236 设计坐标绘制后整体缩到约 216×170 DIP，占用接近常见键鼠同步小猫桌宠；颜色从角色主色派生，切换角色时整套场景一起换色。四款角色共用同一场景，刻晴按图集内容放大 1.12、其余为 1，让可见高度接近。

桌宠可见且「键盘与鼠标跟随 → 镜像键盘输入」开启时，程序安装 `WH_KEYBOARD_LL` / `WH_MOUSE_LL` 全局低级钩子（专用后台线程 + 消息泵）。用户按下任意非修饰键时，键盘上对应键帽高亮，对应一侧的手移动到键位并下压，键位上方浮起键帽标签，显示器依次显示最近按键的标签（最多 8 个，空轨迹时显示静态 `MouseDock`）。按下鼠标左键或右键时，鼠标对应半侧亮起，右手移到鼠标位置。桌宠隐藏、切换显示方式、关闭监听开关或退出程序时立即卸载钩子并清空内存中的输入状态。

右键「键盘与鼠标跟随」提供三个开关，默认全开：

- 「镜像键盘输入」：监听总开关；关闭后卸载钩子，桌宠不再敲键。如果键盘钩子安装失败，菜单会显示「输入监听不可用（系统限制）」；此时鼠标跟随仍可能单独可用。
- 「镜像鼠标点击」：关闭后桌宠不再呈现左右键点击（鼠标 cue 在窗口的 `DrainInput` 阶段丢弃），键盘跟随不受影响；但鼠标钩子仍在，只观察按钮按下，不读取坐标或移动。需要彻底停止两个钩子时关闭「镜像键盘输入」。
- 「显示按键提示」：关闭后不再浮起键帽标签、显示器也不显示按键标签（改为静态 `MouseDock` 字样），键帽高亮和双手动作保留。

桌宠键盘是 37 键紧凑布局（数字、字母、空格），不为功能键和大部分符号键单独画键帽；未绘制的键仍会进入显示器文字与浮起标签，只是不点亮具体键帽。

隐私边界：按键与鼠标事件只在内存中转为动画数据，输入队列随每帧消费、显示器文字随过期清理；不落盘、不写日志、不写入设置文件、不发送到网络或任何第三方。设置文件只保存上述三个布尔开关。详细说明见 [PRIVACY.md](../PRIVACY.md)。

> **明文回显风险**：桌宠会把最近敲击的字符以明文显示在桌面显示器上，且窗口可置顶。输入密码、验证码、私密内容或进行屏幕共享/录屏时，请关闭「显示按键提示」，或直接关闭「镜像键盘输入」停止监听。

「减少动态效果」与待机行为共用同一个开关：开启后停用呼吸、随机小动作、眨眼和双手平滑过渡，键帽高亮、显示器文字与鼠标按键高亮仍会更新，双手直接落到目标键位或鼠标位置。

限制：

- **UIPI**：普通权限进程的低级钩子收不到以管理员身份运行（高完整性）前台窗口的输入，此时桌宠不会跟随。这是 Windows 的完整性级别隔离，不是遗漏的兼容项（参见 [Mandatory Integrity Control](https://learn.microsoft.com/en-us/windows/win32/secauthz/mandatory-integrity-control)）。
- **输入法与键位**：修饰键（Shift、Ctrl、Alt、Win 等）不进入队列；字母和数字固定显示 `A`–`Z` 与 `0`–`9`，符号键按前台键盘布局换算。字符只是物理按键的显示标签，不等于输入法最终上屏的文字。
- **其他输入源**：低级钩子没有过滤注入标记，`SendInput` / `keybd_event` 等程序注入的按键也会被镜像；触摸板、触控笔、屏幕键盘和远程桌面的行为尚未逐项验证。部分全屏游戏、反作弊或受保护进程可能拦截钩子。
- **监听状态**：判断依据是桌宠窗口的 WPF `IsVisible`。被其他窗口遮挡、最小化或位于其他虚拟桌面时窗口仍算显示状态，监听可能继续；需要绝对停止时请关闭「镜像键盘输入」。
- **验证状态**：已完成 Debug/Release 构建（Release 0 warning / 0 error）、172 项 Checks（171 通过、0 skipped，1 项 Taskbar 透明像素检查在改动前的 HEAD 上同样失败，其中 6 项键盘桌宠检查全部通过）、39,445 条 ProtocolTests，以及 `--pet-input-live` 用 `keybd_event` 合成 F24 的钩子接收与停止释放探针。这些都是自动化或合成输入验证；桌面端真实人工敲击（如依次按下 `QBDKUX`）与左右键点击的跟随效果仍未验收，不能把自动化检查当作真机输入跟随的结论。

## 待机行为

右键「待机行为」可独立开关随机小动作、眨眼与静息，并在 50%、100%、150% 三档调整自主动作速度和频率。「减少动态效果」同时关闭这些动画。现有点击、拖拽、滚轮缩放、充电和刻晴动作入口继续可用。鼠标停留时角色会轻微向光标倾斜，拖拽释放时在固定窗口内缓冲落地。

空闲时从微倾、轻跳和挥手中按权重选择，动作各有时长和冷却，并避免连续两次选择同一个动作。支持眨眼帧的角色有独立随机时钟和偶尔连眨。闲置约四分钟进入静息姿态，放慢呼吸和绘制频率。移动光标至角色可唤醒。隐藏窗口暂停计时；恢复、充电及低电量状态保留各自的原有表现。

扩展动作时，在 `DesktopPetBehavior.Actions` 中声明权重、持续时间和冷却，在角色图集加入同画布、同脚底锚点的透明帧，再在渲染层绑定动作。现有素材为整身图集。独立眼球转动、头手局部运动、发丝和衣物回弹需要对齐的透明部位层或同画风逐帧图。哈欠、揉眼、伸懒腰、挠头、摸脸、低头、托腮、整理、转身、跺脚、喷嚏、回头、蹲坐、点头及惊醒需要各角色独立帧，建议每个动作制作起始、关键姿态、恢复三阶段，并在实际显示尺寸核对定位。现有静息使用原待机图和慢呼吸。

## 同类桌宠参考

调研同类产品时只借鉴交互取舍，不复制实现：

- [Shimeji-ee](https://sourceforge.net/app/shimeji-ee/) 用可替换的角色包和按包配置的行为，角色会沿窗口边缘移动、在任务栏休息；借鉴「角色素材与场景参数分离」，MouseDock 让四款角色共用同一桌前场景，只换图集与配色。
- [Bongo Cat Mver](https://xiazai.zol.com.cn/baike/570690.shtml) 一类键盘替身工具把真实键鼠操作实时映射到角色上，支持纯键盘或键鼠模式、置顶与锁定、屏幕缩放校正；借鉴其键盘与鼠标分开开关、显示器字符可隐藏、以及按 DPI 适配的做法。
- [Desktop Goose](https://sourceforge.net/app/desktop-goose/) 用 `config.goos` 和资源目录配置行为，官方说明也提示多开或高频特效会拖慢机器；借鉴「强度可调、可完全关闭、默认低负载」，MouseDock 只在跟随开启时增加一个钩子线程，不额外轮询。
- [CocoPet](https://github.com/ZDreamPY/CocoPet) 按电脑操作状态切换桌宠表现：打字时敲键盘、长时间不动睡觉、全屏看视频或玩游戏时安静；MouseDock 已实现「只在桌宠可见时联动、空闲进入静息」，全屏应用检测不在本版范围。
