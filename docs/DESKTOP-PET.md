# 小新电量桌宠

从 MouseDock 设置的「桌宠」区域或托盘右键菜单选择「显示／隐藏桌宠」。电量框列出所有勾选显示的设备，点列表项可切换角色跟随的设备。右键「显示设备」可勾选或取消，设置页会同步。点击小新会挥手，拖动小新可换位置，靠近工作区边缘时自动贴边。右键可锁定位置、调整尺寸、电量形状和动效，以及切换减少动态效果和全局满电提醒。

桌宠复用 BatteryService。默认跟随首台可显示设备，也可固定跟随设备实例。过期读数标注「上次」，未知值显示「—」。同一设备每次有效读数变更会更新数字并平滑移动电量边界。接电姿势只在确认进入充电时播放一次，后续使用吃饼干姿势。明确充满触发 BatteryService 的原有通知事件和一次庆祝动作。

内置素材为 image_gen 生成的透明六姿势图集，按参考图绘制红衣黄裤的小新，依次包含站立、挥手、打哈欠、拿 USB 插头、坐着吃饼干和双手庆祝。首版以姿势切换和呼吸变形实现动画。素材不含示例电量或文字。

**未完成**。各设备在充电过程中的实时百分比和满电字段仍需逐设备复核，尤其是 Neon 75 Air 接线后回报 100% 的情况。桌宠沿用现有协议的可信度和过期判定。

## 角色选择

托盘菜单的「显示／隐藏桌宠」打开浮窗。右键「桌宠角色」可切换蜡笔小新、心月狐和小鸟游六花，重启后恢复所选角色。

心月狐持扇站立，低电时抱尾打盹，充电时托起小狐灯，确认满电后抬手庆祝。六花拄紫伞站立，低电时抱伞入睡，充电时扶住眼罩并举伞，确认满电后举伞庆祝。两套姿势加入短暂眨眼帧。六花的伞尖星火在充电时明暗变化，满电庆祝时飘散。低电气泡使用琥珀边框和电量弧。

两个透明图集由内置 image_gen 依据用户参考图生成。每张 3×2 图集按待机、挥手、低电、眨眼、充电、庆祝排列，只包含角色和道具。流光和百分比由应用运行时绘制。
