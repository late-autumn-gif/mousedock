# MouseDock 桌宠

在「设置 → 显示方式 → 桌宠」开启，或从托盘菜单选择「切换到桌宠」。桌宠、主面板、迷你窗口、悬浮图标、任务栏和屏幕右侧共用同一显示方式选择。旧版开启了独立桌宠开关的设置会迁移到桌宠模式。

右键「桌宠角色」可选择蜡笔小新、小鸟游六花或心月狐。设备卡片在左侧显示图标和名称，名称下方显示电量条，右侧显示百分比。每张卡片最多显示六台已勾选设备，过期读数变暗。点击设备行可切换角色跟随的设备。右键「显示设备」可更改与设置页同步的勾选状态。

三个角色的配色与探头素材各自独立。拖动头像可调整位置，右键菜单可调整大小、锁定位置、选择充电动效或启用减少动态效果。明确满电时仍使用原有的充电会话提醒。

内置 imagegen 根据用户的三张卡片参考图制作透明图集，三列依次为小新、六花和心月狐，两行分别为睁眼探头和微笑探头。图集仅包含角色、手和道具，界面、设备和百分比由应用绘制。
